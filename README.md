
<h1>📖 About</h1>

This is my first personal project built entirely from scratch using HTML, CSS, and JavaScript — no frameworks, no libraries, just the fundamentals.

I'm Abdelfattah, a web developer and cybersecurity researcher, and I built this calculator as a hands-on way to practice core front-end concepts: DOM manipulation, event handling, and responsive layout design.

<h1>🎯 Purpose</h1>
<h3>This project was built to strengthen my skills in:</h3>
<h5>JavaScript fundamentals</h5>
<h5>DOM manipulation</h5>
<h5>Event handling</h5>
<h5>CSS layouts & Flexbox/Grid</h5>
<h5>Responsive web design</h5>
<h5>Building interactive web applications from the ground up</h5>
<h1>✨ Features</h1>
<h5>➕ Addition</h5>
<h5> subtraction</h5>
<h5> multiplication</h5>
<h5> and division</h5>
<h5>🔢 Decimal number support</h5>
<h5>🔁 Clear / Reset functionality</h5>
<h5>📱 Fully responsive design (mobile, tablet, desktop)</h5>
<h5>🎨 Simple, clean, and intuitive user interface</h5>
